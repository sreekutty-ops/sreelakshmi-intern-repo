# Introduction to SQL for Data Analysis

## How SQL helps in data analysis
- SQL allows retrieval of structured data efficiently.
- Enables filtering, sorting, and aggregation to generate insights quickly.

## Difference between filtering (WHERE) and aggregation (GROUP BY)
- WHERE filters individual rows before aggregation.
- GROUP BY groups rows to perform calculations like SUM, COUNT, AVG.

## Retrieving and analyzing user activity data in Focus Bear’s database
- Use SELECT with WHERE to focus on specific users or dates.
- Use GROUP BY to summarize metrics like total focus minutes per user.
- ORDER BY helps prioritize insights (e.g., most active users).

## Why learning SQL is important even if using Python
- SQL queries can handle large datasets directly in the database.
- Python works well with SQL output but cannot replace efficient database querying.
