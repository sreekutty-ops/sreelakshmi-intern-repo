# Connecting Python & Pandas to SQL

## Why is it useful to query databases directly from Python instead of using a SQL client?
Querying directly from Python automates data retrieval, eliminates manual work, and integrates analysis and reporting into one workflow.

## How does psycopg differ from psycopg2?
`psycopg` is the modern, rewritten version of `psycopg2`. It supports Python 3.8+, is faster, and simplifies connection and transaction handling.

## How can Pandas help with post-query data transformation?
Pandas allows you to filter, group, aggregate, and visualize data easily. You can perform complex transformations without writing complicated SQL queries.

## How could this integration be used to generate automated reports for Focus Bear?
By combining SQL queries with Pandas scripts, Focus Bear can automatically generate weekly or monthly analytics reports on app usage, engagement trends, and user behavior without manual intervention.
