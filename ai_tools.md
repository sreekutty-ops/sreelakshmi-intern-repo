# AI Tools for Development

## Which AI tools did you try?

I used ChatGPT to help with coding, debugging, and understanding new technical concepts.  
I also installed GitHub Copilot in VS Code to get code suggestions while typing.

---

## What worked well?

ChatGPT was very helpful for:
- Explaining Git, SQL, and programming concepts
- Generating sample code
- Debugging errors when something didn’t work

GitHub Copilot was useful for:
- Autocompleting code
- Suggesting function names and syntax
- Speeding up writing simple programs

---

## What didn’t work well?

Sometimes Copilot suggests code that is not exactly what I want, so I still need to understand the code and edit it.  
AI tools can also be wrong sometimes, so I need to double-check answers.

---

## When is AI most useful for coding?

AI is most useful when:
- Learning new concepts
- Writing boilerplate code
- Debugging errors
- Understanding unfamiliar code

It helps me work faster and with more confidence.
